# E-Commerce Customer Segmentation & CLV Analysis

## 📌 Project Overview
An end-to-end data analytics project analyzing e-commerce customer behavior using RFM (Recency, Frequency, Monetary) segmentation and Customer Lifetime Value (CLV) metrics.

## 🛠️ Tech Stack & Tools
- **Database:** Neon.tech (PostgreSQL)
- **Data Processing:** Python (Google Colab, SQLAlchemy, Pandas)
- **Visualization:** Tableau Public
- **Language/Query:** SQL, Python

## 📊 Key Findings & Insights
- Identified high-value VIP and Loyal customer segments contributing significantly to total revenue.
- Highlighted at-risk customers for targeted retention campaigns.
